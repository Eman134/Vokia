# PEN-010 · Modo automático da classificação do pedido

**Status:** aberta
**Origem:** Barra de ação, item 10
**Referências:** [barra-de-acao.puml](../diagramas/barra-de-acao.puml) · [Design.html](../prototipo/Design.html), quadro "Barra de ação · variações"

## Situação

**Situação:** a Iara classifica o pedido como pequeno ou feature e o padrão é confirmar com balão (ver [Decisões aceitas](../PENDENCIAS.md#decisões-aceitas)). O modo automático (pequeno vai para Enviado, feature vai para Triagem) só existe no diagrama. O código do Dock diz "num modelo leve" e o texto do PedidoNovo diz "a Iara acha que é uma feature", sem dizer se a Iara usa um modelo local.

## Decisão necessária

- Se o modo automático é configurável e onde o usuário o escolhe.
- Quando um modelo local entra e se a Iara continua como quem apresenta a classificação.
- O critério que separa pedido pequeno de feature.
