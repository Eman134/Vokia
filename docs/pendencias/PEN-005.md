# PEN-005 · Compositor de pedido: envio, destinatário e tamanho

**Status:** aberta

**Referências:** [barra-de-acao.puml](../diagramas/barra-de-acao.puml) · [Design.html](../prototipo/Design.html), quadro "Barra de ação · variações"

## Situação

**Situação:** no PedidoNovo, o botão de envio ("Enviar para a Iara" ou "Mandar para <agente>") não tem ação. "Para quem" escolhe um agente (`a.pick`) e "Tamanho" troca entre feature e pequeno (`o.pick`), mas o efeito de cada escolha não está definido.

## Decisão necessária

- O que acontece ao enviar: para a Iara (triagem), para um agente direto ou para a fila dele.
- Se a escolha de tamanho muda o caminho do pedido ou só o texto exibido.
