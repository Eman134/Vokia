## Decisões aceitas

Decisões do usuário sobre a barra de ação. Os requisitos de `backlog/` as tratam como regra.

| Tema | Decisão |
|---|---|
| Decisão em linha | Entra só permissão de comando e pergunta com até duas opções curtas. O resto vai para o painel. |
| Esperando você (onboarding) | Ignorado pelo usuário. Não entra no diagrama. |
| Fim do fluxo | O botão "Pronto" na última etapa encerra o fluxo. |
| Saída do Erro | Sai quando um novo teste passa. |
| Concluído | Sai após um tempo ou quando começa outra tarefa. A duração está em [PEN-001](pendencias/PEN-001.md). |
| Prioridade | Pausado vence Erro. Ordem: Pausado > Erro > Precisa de você > Trabalhando > Repouso. Em paralelo e Concluído estão em [PEN-002](pendencias/PEN-002.md). |
| Pensando | Termina quando o plano fica pronto. A posição na ordem de prioridade está em [PEN-012](pendencias/PEN-012.md). |
| Classificação do pedido | A Iara classifica hoje. Um modelo local fica para o futuro, com modo automático ([PEN-010](pendencias/PEN-010.md)). Por enquanto o padrão é confirmar com balão. |
| Balão fechado | Fechar um balão não impede os próximos na mesma sessão. |
| Manter com o Davi | Volta a Enviado. |
| Momento com painel aberto | Espera na fila até o painel fechar. |
| Timer de 8 s e atalhos | Implementar o timer de 8 s do balão e os atalhos Esc, ⌘J, ⌥1 e ⌥2. |
| Mascote | Só em mensagens gerais e no balão de limite de plano (75% pisca, 90% brasa, renovou faíscas). Ver [PEN-011](pendencias/PEN-011.md). |
| Contador 3 | O número 3 do ícone da Vokia é o total de decisões pendentes do painel. O dono é o requisito [011](backlog/011.md) (Painel de decisões), fora do diagrama. |
