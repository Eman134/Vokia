# 069 · Threads com estado e agrupamento

## Objetivo

Mostra na lista de threads qual está viva, qual precisa do usuário e a que card pertence, separando as concluídas.

## Comportamento

- Cada thread mostra o retrato do agente atual, o card ligado e um ponto de estado: trabalhando, precisa de você, não lido ou concluída.
- A lista se divide em "Ativas" e "Concluídas (n)", esta recolhida.
- A thread de um card que foi para o Done passa sozinha para "Concluídas".
- Card concluído só vira thread se teve conversa; a thread aberta mantém o grupo "Concluídas" aberto.
- O ponto de estado mostra "trabalhando" e "precisa de você" (decisão pendente ou permissão de um agente que trabalha no card); "não lida" continua na bolinha de leitura.
- Só apresentação: não cria comando novo no `dispatcher.rs`.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado 19 threads com 2 ativas, quando a lista é exibida, então mostra 2 linhas em "Ativas" e "Concluídas (17)" recolhida.
2. Dado uma thread com decisão pendente, quando a lista é exibida, então ela mostra o estado "precisa de você".
3. Dado o card de uma thread movido para o Done, quando a lista é atualizada, então a thread aparece em "Concluídas".
