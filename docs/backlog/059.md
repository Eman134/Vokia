# 059 · Visão em lista para consulta

## Objetivo

Oferece uma tabela ordenável dos cards, para consultar o Backlog grande e o histórico do Done.

## Comportamento

- Um seletor "Quadro / Lista" no cabeçalho da página de Tasks.
- A lista é uma tabela com ID, título, coluna, responsável, etiquetas, custo e data, ordenável por coluna.
- A lista usa os mesmos filtros de [058](058.md).
- É o destino do "Ver todos" do Done.
- Clicar numa linha abre o card como no quadro.
- Só apresentação: não cria comando novo no `dispatcher.rs`.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado a lista aberta, quando o usuário ordena por custo, então os cards mais caros aparecem primeiro.
2. Dado a lista aberta, quando o usuário clica numa linha, então o card abre como no quadro.
3. Dado o link "Ver todos" do Done, quando o usuário clica, então a lista abre filtrada pela coluna Done.
