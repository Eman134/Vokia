# 040 · Notificação nativa do sistema

## Objetivo

Avisa pelo sistema operacional quando algo precisa do usuário e o Vokia não está em foco, para que uma decisão parada não passe despercebida enquanto o usuário trabalha em outra janela.

## Comportamento

- Com a janela do Vokia fora de foco ou minimizada, o sistema mostra uma notificação nativa quando uma decisão nova é aberta (permissão, pergunta, escolha, revisão).
- A notificação mostra o agente e o título da decisão.
- Clicar na notificação traz o Vokia para a frente, quando o sistema operacional permite.
- Com a janela em foco, nenhuma notificação nativa aparece; o aviso fica na barra de ação.
- A mesma decisão não gera duas notificações.
- Uma configuração liga e desliga as notificações; o padrão é ligado.
- A configuração fica disponível pelos comandos de configurações, pelo MCP e pelo `vokia-cli`.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado o Vokia fora de foco, quando um agente abre uma decisão, então aparece uma notificação do sistema com o agente e o título da decisão.
2. Dado o Vokia em foco, quando um agente abre uma decisão, então nenhuma notificação do sistema aparece.
3. Dado as notificações desligadas na configuração, quando uma decisão é aberta com o app fora de foco, então nenhuma notificação aparece.
4. Dado uma decisão já notificada, quando ela é emitida de novo, então nenhuma segunda notificação aparece.
