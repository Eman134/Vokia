# 066 · Permissões automáticas dentro da atividade do turno

## Objetivo

Recolhe as aprovações automáticas de comando dentro da atividade do turno, para que a resposta do agente não fique escondida entre linhas de PowerShell.

## Comportamento

- Aprovações em modo bypass ou auto deixam de ser linhas soltas e entram no `ActivityRun` do turno como linhas de comando.
- Fechado, o bloco mostra uma frase: "<agente> rodou n comandos (git status, git diff…) ▸".
- Aberto, cada linha mostra o comando resumido (`friendlyCommand`); o texto inteiro fica num `UiCommandBlock` sob demanda.
- Permissão que pediu decisão ao usuário e falhas continuam visíveis fora do bloco.
- Só apresentação: não cria comando novo no `dispatcher.rs`.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado um turno com 7 aprovações automáticas, quando a conversa é exibida, então aparece um bloco recolhido só, com a frase de 7 comandos.
2. Dado esse bloco recolhido, quando o usuário expande, então as 7 linhas de comando aparecem.
3. Dado um turno com aprovações automáticas e resposta do agente, quando a conversa é exibida, então a resposta fica visível sem rolar.
4. Dado uma permissão que pediu decisão ao usuário, quando a conversa é exibida, então ela continua visível fora do bloco.
