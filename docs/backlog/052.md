# 052 · Instruções da raiz do projeto no prompt do agente

## Objetivo

Coloca o `CLAUDE.md` e o `AGENTS.md` da raiz do projeto direto no prompt do agente, para que ele não gaste uma ida à API lendo esses arquivos a cada sessão nova.

## Comportamento

- Ao montar o contexto do projeto, o sistema lê `CLAUDE.md` e `AGENTS.md` da raiz do projeto, se existirem, e inclui o texto no prompt de sistema do agente.
- O texto incluído tem um teto de tamanho; passando do teto, entra cortado e com aviso de que está incompleto.
- A regra do prompt passa a dizer que as instruções da raiz já vêm no prompt e que, antes de editar arquivo numa subpasta, o agente ainda lê o `CLAUDE.md` ou `AGENTS.md` dela.
- Sem esses arquivos, o prompt fica como hoje.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado um projeto com `CLAUDE.md` na raiz, quando o agente abre sessão, então o prompt contém o texto do arquivo.
2. Dado um `CLAUDE.md` maior que o teto, quando o prompt é montado, então o texto entra cortado e marcado como incompleto.
3. Dado um projeto sem `CLAUDE.md` nem `AGENTS.md`, quando o agente abre sessão, então o prompt não tem a seção de instruções.
