# 009 · Compositor de novo pedido

## Objetivo

Um modal para escrever um pedido novo: o usuário descreve o que precisa, escolhe o tamanho (pequeno ou feature) e o agente de destino. O modal abre pelo menu da barra.

## Comportamento

- O usuário escolhe "Nova feature" ou "Novo pedido" no menu ☰. O modal abre com o tamanho "Feature".
- O modal mostra o título "Novo pedido", a linha "loja-online · Time Web" e o campo "O que você precisa?".
- Quando o pedido vem de um trecho ou arquivo, o modal mostra "Vem de <origem> · remover", o trecho citado e "o trecho, o arquivo e a conversa vão junto para quem pegar o pedido".
- A dica do campo é "@ menciona um agente · / comandos · arraste specs ou wireframes".
- O bloco "Tamanho" mostra a sugestão atual. Os dois tamanhos são:
  - "Pequeno": "Um ajuste, um bug ou uma pergunta. Vai direto para um agente."
  - "Feature": "Vira um card pai. A líder faz a triagem e desdobra em micro-tarefas."
  - Com "Feature", a sugestão diz "a Iara acha que é uma feature". Com "Pequeno", diz "você escolheu pequeno".
- O bloco "Para quem" lista três agentes: "Davi" (front · fila 2), "Nina" (back · livre) e "Téo" (qualidade · fila 1). O agente padrão é Davi.
- O modal mostra os quatro passos do fluxo: "Card pai no Backlog", "Perguntas, se faltar algo", "Desdobra em micro-tarefas" e "Você aprova a proposta".
- O rodapé diz "cria a branch quando a primeira micro-tarefa começar" com Feature e "sem card · fica no git" com Pequeno.
- O botão principal diz "Enviar para a Iara" com Feature e "Mandar para <agente>" com Pequeno. O clique no fundo do modal fecha o modal. O botão "Cancelar" aparece no quadro sem ação definida.
- O quadro traz a frase "Não vira card. Entra na fila do agente, e o rastro fica no commit e no PR. Se ele perceber que é maior, devolve como feature para a triagem.", que aparece sempre no modal.

## Estados e transições

- `barra-de-acao.puml › Interacao › Compositor aberto (CompositorAberto)`: o modal de novo pedido. Fechado é `Expandida (Expandida)`.
- Transição de Menu aberto para Compositor aberto: ação "Nova feature" ou "Novo pedido" no menu (`ação Nova feature ou Novo pedido`).
- Transição de Compositor aberto para Expandida: "Fechar" ou clique no fundo (`Fechar ou fundo`).
- A troca entre os tamanhos Pequeno e Feature dentro do modal não está modelada no diagrama.

## Critérios de aceite

1. Dado que a barra mostra o menu ☰, quando o usuário escolhe "Nova feature", então o modal abre com o tamanho "Feature" e o botão principal diz "Enviar para a Iara".
2. Dado que o modal está aberto com "Feature", quando o usuário escolhe "Pequeno", então o rodapé diz "sem card · fica no git" e o botão principal diz "Mandar para Davi" (agente padrão).
3. Dado que o tamanho é "Pequeno", quando o usuário escolhe "Nina" em "Para quem", então o botão principal diz "Mandar para Nina".
4. Dado que o modal está aberto, quando o usuário clica em "Fechar" ou no fundo, então o modal fecha.

## Pendências

- Pendência do diagrama (4): a regra que separa pequeno de feature. O modal mostra a sugestão "a Iara acha que é uma feature", mas o quadro não diz quem decide quando o usuário não escolhe o tamanho ([PEN-010](../pendencias/PEN-010.md)).
- Efeito de "Para quem" e do tamanho no envio. O botão "Enviar para a Iara" ou "Mandar para <agente>" não tem ação no protótipo ([PEN-005](../pendencias/PEN-005.md)).
- Efeito do botão "Cancelar", que aparece no quadro sem ação definida. [PEN-029](../pendencias/PEN-029.md)
- O quadro mostra os textos do modal, mas as opções e os passos estão no código do componente PedidoNovo. Confirmar no navegador que o quadro mostra os mesmos textos. [PEN-030](../pendencias/PEN-030.md)
