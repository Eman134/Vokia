# 074 · Atalhos de teclado

## Objetivo

Dá atalhos de teclado para as ações mais frequentes do quadro.

## Comportamento

- `N` abre um pedido novo, `/` foca a busca, `J` e `K` navegam entre cards, `Enter` abre o card e `?` mostra a lista de atalhos.
- Os atalhos ficam desligados quando o foco está num campo de texto.
- O listener é removido quando a tela sai.
- Só apresentação: não cria comando novo no `dispatcher.rs`.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado o quadro com foco fora de campo de texto, quando o usuário tecla `N`, então abre um pedido novo.
2. Dado o foco num campo de texto, quando o usuário tecla `N`, então a letra é digitada e nenhum atalho dispara.
3. Dado o quadro, quando o usuário tecla `?`, então aparece a lista de atalhos.
4. Dado o quadro com um card focado, quando o usuário tecla `J` e depois `Enter`, então o card seguinte abre.
