# 006 · Campo de pedido

## Objetivo

O campo é onde o usuário pede algo ao projeto, direto da barra de ação. Ele aparece quando a barra está expandida, recebe o foco e mostra um placeholder que indica o que pode ser digitado.

## Comportamento

- O campo aparece quando a barra está expandida. A expansão e a volta à compacta pelo foco são do [002](002.md).
- Com o campo vazio, o placeholder base é "Peça algo ao projeto ou mencione @alguém". Em algumas páginas o placeholder é outro, como "Peça algo e escolha o projeto" (página Projetos) e "Mensagem para #loja-online" (página Chat).
- A anatomia da barra nomeia este campo como "3 pedido, @ e /" (quadro "Barra de ação · variações", seção "Anatomia").
- O envio pelo Enter aparece como dica no balão de escrita: "Enter manda para a Iara ver o tamanho". O protótipo não executa esse envio; o componente só troca o valor do campo.
- No painel "Acontecendo agora" aberto em um agente, o quadro mostra o campo com "Mensagem para @Davi · entra na fila dele". O protótipo não diz quando esse placeholder aparece.

## Estados e transições

- `barra-de-acao.puml › Interacao › Expandida (Expandida)`: o campo não tem foco.
- `barra-de-acao.puml › Interacao › Digitando (Digitando)`: o campo tem foco. A transição de Expandida para Digitando é o clique no campo (`clique no campo`); a volta é `sai do campo`.
- O diagrama modela o Enter como transição de `barra-de-acao.puml › Aviso › Sem aviso (SemAviso)` para `Classificando (Classificando)` (`Enter no campo`), detalhada em [010](010.md). O efeito do envio no campo está na pendência abaixo.
- As transições internas de Digitando, "digita @" e "digita /", são dos requisitos 007 e 008.

## Critérios de aceite

1. Dado que a página é Projetos e o campo está vazio, quando a barra está expandida, então o placeholder é "Peça algo e escolha o projeto".
2. Dado que a página é Mapa do time (padrão do componente) e o campo está vazio, quando a barra está expandida, então o placeholder é "Peça algo ao projeto ou mencione @alguém".
3. Dado que a página é Chat e o campo está vazio, quando a barra está expandida, então o placeholder é "Mensagem para #loja-online".

## Pendências

- O Enter envia? O balão de escrita diz "Enter manda para a Iara ver o tamanho", mas o componente só troca o valor do campo. Falta definir o efeito do envio ([PEN-005](../pendencias/PEN-005.md) e [PEN-006](../pendencias/PEN-006.md)).
- Efeito de ⌘↵, citado no balão de escrita como "abre o pedido detalhado" ([PEN-006](../pendencias/PEN-006.md)).
- Escolha do projeto no campo quando há mais de um projeto. O quadro mostra "Peça algo e escolha o projeto", sem regra ([PEN-008](../pendencias/PEN-008.md)).
- Quando o placeholder "Mensagem para @Davi · entra na fila dele" aparece: só há o texto no quadro, sem regra. [PEN-022](../pendencias/PEN-022.md)
