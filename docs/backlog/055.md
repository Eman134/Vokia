# 055 · Done compacto, agrupado e recolhível

## Objetivo

Transforma o Done num arquivo de consulta: card em uma linha, agrupado por data de conclusão e recolhível, para não gastar espaço com o que ninguém opera.

## Comportamento

- O card do Done vira uma linha: ID, título truncado, avatar e tempo relativo ("há 2h"), sem descrição, anexos e barra de progresso.
- Os cards se agrupam por data de conclusão: "Hoje", "Esta semana" e "Anteriores (n)", este último recolhido.
- Só os 10 mais recentes aparecem; o link "Ver todos (n)" abre a lista completa ([059](059.md)).
- Um botão no título recolhe a coluna numa faixa vertical estreita com nome e contagem; a escolha fica salva por projeto no navegador.
- O backend grava `closedAt` quando o card entra no Done e devolve o campo na listagem; o campo aparece nas leituras de card do MCP e do `vokia-cli`, sem comando novo.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado um card concluído agora, quando o Done é exibido, então ele aparece no topo de "Hoje".
2. Dado o Done com mais de 10 cards, quando é exibido, então só os 10 mais recentes aparecem e o link "Ver todos" mostra o total.
3. Dado o Done recolhido, quando o app é reiniciado, então a coluna continua recolhida e as outras quatro ocupam a largura.
4. Dado um card movido para o Done, quando um agente lê o card pelo MCP, então o card traz `closedAt`.
