# 039 · PR e vigilância de CI

## Objetivo

Fecha o ciclo do card até o merge sem o usuário sair do app: o card abre o PR, o sistema vigia o CI e as revisões e devolve problemas ao agente pela mesma regra de devolução que o Vokia já usa.

## Comportamento

- Um card aceito na revisão mostra a ação "Abrir PR". O sistema faz push da branch do card e abre o PR pelo `gh`, com o título do card e um resumo do plano, do parecer da revisão e da verificação.
- O PR fica vinculado ao card (o mesmo vínculo de `link_git_ref`).
- Enquanto o PR está aberto, o sistema consulta checks, comentários de revisão e conflito em intervalo fixo.
- Check que falha, comentário de revisão novo ou conflito com a base vira um pedido ao agente autor, com o trecho do log ou o texto do comentário, pela seta de devolução e respeitando o limite de tentativas da orquestração. Passado o limite, vira decisão para o usuário.
- PR mesclado move o card para Done e dispara a limpeza do worktree. PR fechado sem merge vira decisão para o usuário.
- Sem `gh` instalado ou autenticado, "Abrir PR" fica desativada com o motivo.
- A vigilância respeita a pausa por limite de uso: não acorda agente com o time pausado.
- Abrir PR e consultar o estado ficam disponíveis como comandos pelo MCP e pelo `vokia-cli`.

## Estados e transições

Não modelado no diagrama. Estados do PR no card: aberto, CI rodando, CI falhou, CI passou, conflito, mesclado, fechado.

## Critérios de aceite

1. Dado um card aceito com `gh` autenticado, quando o usuário escolhe "Abrir PR", então o PR é criado com o título do card e fica vinculado a ele.
2. Dado um PR com check falhando, quando a vigilância consulta o PR, então o agente autor recebe um pedido com o nome do check e o trecho do log.
3. Dado um PR que falhou mais vezes que o limite de devoluções, quando falha de novo, então nenhum agente é acordado e uma decisão aparece para o usuário.
4. Dado um PR mesclado, quando a vigilância consulta o PR, então o card vai para Done e a limpeza do worktree começa.
5. Dado o `gh` ausente, quando o usuário abre o card aceito, então "Abrir PR" está desativada com o motivo.
6. Dado o time pausado por limite de uso, quando o CI falha, então nenhum agente é acordado até a pausa acabar.
