# 048 · Issues do GitHub e do Linear no backlog

## Objetivo

Traz as issues do repositório para o backlog do Vokia, ligando card, issue e PR, para o usuário não manter duas listas.

## Comportamento

- O usuário conecta o projeto às issues do GitHub (pelo `gh`) e, opcionalmente, ao Linear.
- O backlog mostra as issues abertas numa aba de importação; o usuário escolhe quais viram card.
- O card importado guarda o link da issue. Ao abrir o PR do card, o PR referencia a issue.
- Card concluído comenta e fecha a issue, se o usuário permitir na configuração.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado o projeto conectado ao GitHub, quando o usuário abre a aba de importação, então as issues abertas aparecem.
2. Dado uma issue importada, quando o card abre o PR, então a descrição do PR referencia a issue.
3. Dado um card importado concluído e o fechamento permitido, quando o card vai para Done, então a issue é fechada com um comentário.
