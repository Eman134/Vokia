# 058 · Barra de filtros real

## Objetivo

Troca o filtro único de feature por uma barra de busca e filtros que ajuda a achar cards e o que precisa do usuário.

## Comportamento

- A barra tem busca por texto e ID (atalho `/`), filtro por agente (avatares clicáveis), por tipo (tarefa ou feature), por etiqueta e o atalho "Precisa de mim".
- "Precisa de mim" mostra só cards com pergunta sem resposta, proposta pendente ou erro.
- O seletor de densidade "Compacto / Confortável" fica no fim da linha.
- Os filtros vão para a query da rota e sobrevivem ao recarregar.
- O `UiSegmented` de feature vira uma opção do filtro de etiqueta.
- Só apresentação: não cria comando novo no `dispatcher.rs`.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado o quadro, quando o usuário digita "376" na busca, então só o `item-376` aparece.
2. Dado cards com e sem pendência, quando o usuário liga "Precisa de mim", então só aparecem cards com pergunta aberta, proposta pendente ou erro.
3. Dado filtros aplicados, quando a página é recarregada, então os mesmos filtros continuam aplicados.
4. Dado o foco fora de um campo de texto, quando o usuário tecla `/`, então o foco vai para a busca.
