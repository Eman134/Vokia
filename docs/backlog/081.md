# 081 · Visão em lista dos artefatos

## Objetivo

Mostra dezenas de artefatos de uma vez quando o usuário está consultando, não lendo.

## Comportamento

- Um alternador "Grade / Lista" na linha das abas.
- Na lista, cada linha tem tipo, título, estado, etapas feitas de total e atualização relativa.
- Clicar na linha abre o artefato, como o card da grade.
- A escolha fica salva por projeto no navegador.
- Só apresentação: não cria comando novo no `dispatcher.rs`.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado 48 artefatos numa janela de 1080px de altura, quando a lista é exibida, então ao menos 20 linhas aparecem sem rolar.
2. Dado a lista escolhida, quando o app é reiniciado, então a página abre em lista.
3. Dado uma linha da lista, quando o usuário tecla Enter nela, então o artefato abre.
