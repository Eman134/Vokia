# 054 · Rolagem por coluna com cabeçalho fixo

## Objetivo

Faz cada coluna do quadro de Tasks rolar sozinha, para que uma coluna longa (como o Done com 60 cards) não arraste as outras nem esconda o cabeçalho e o "Novo pedido".

## Comportamento

- A página de Tasks não rola; o quadro ocupa a altura que sobra.
- Cada coluna tem rolagem própria.
- O título da coluna (nome, contagem e traço) fica fixo no topo dela.
- No celular, com uma coluna só, a página continua rolando como hoje.
- Ao trocar de projeto, cada coluna volta ao topo.
- Só apresentação: não cria comando novo no `dispatcher.rs`.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado 60 cards no Done, quando o usuário rola o Done, então as outras colunas não se movem.
2. Dado o Done rolado até o fim, quando o usuário olha o topo da tela, então o botão "Novo pedido" e o título das colunas continuam visíveis.
3. Dado colunas roladas, quando o usuário troca de projeto, então cada coluna volta ao topo.
4. Dado a largura de celular, quando o quadro é exibido, então a página rola normalmente.
