# 033 · Telas de sistema: splash, atualização, vazio e CLI ausente

## Objetivo

Define as quatro telas de sistema do app: o splash de conexão, o aviso de atualização pronta, a tela de vazio sem features e a tela de erro quando a CLI do Claude Code não é encontrada.

## Comportamento

- Splash: mostra a marca "Vokia" e a legenda "Conectando Claude Code e Codex…".
- Aviso de atualização: mostra "Versão 0.3.0 pronta" (valor de exemplo do quadro), a legenda "instala quando reiniciar" e o botão "Reiniciar".
- Vazio: mostra o bloco Vazio de [029](029.md), com a legenda "Peça a primeira na barra de ação.".
- Erro: mostra "Claude Code não encontrado", a instrução "Instale a CLI e faça login nela. A Vokia não guarda seu login." e o botão "Verificar de novo".

## Estados e transições

Não modelado no diagrama.

Estados visuais que o quadro mostra:
- Splash: "Conectando Claude Code e Codex…".
- Aviso de atualização: "Versão 0.3.0 pronta".
- Vazio: bloco Vazio de [029](029.md).
- Erro: "Claude Code não encontrado".

## Critérios de aceite

1. Dado o app abrindo e conectando, quando a tela de splash aparece, então mostra a legenda "Conectando Claude Code e Codex…".
2. Dado uma atualização pronta, quando o aviso aparece, então mostra "Versão 0.3.0 pronta" (exemplo do quadro), a legenda "instala quando reiniciar" e o botão "Reiniciar".
3. Dado um projeto sem features, quando a tela de vazio aparece, então mostra o bloco Vazio de [029](029.md) com a legenda "Peça a primeira na barra de ação.".
4. Dado a CLI do Claude Code ausente, quando a tela de erro aparece, então mostra "Claude Code não encontrado", a instrução "Instale a CLI e faça login nela. A Vokia não guarda seu login." e o botão "Verificar de novo".
