# 065 · Atividade do card com texto e tempo humanos

## Objetivo

Corrige o texto gerado na atividade do card e mostra datas relativas, com a data completa à mão.

## Comportamento

- A atividade mostra tempo relativo ("ontem, 15:38"), com a data completa no `title`.
- O texto de criação não repete a palavra "time" quando o time se chama "Time": vira "criou o card para o time (líder Axiom)".
- O texto vem do backend, então a correção vale também para as leituras pelo MCP e pelo `vokia-cli`.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado um time chamado "Time", quando um card é criado para ele, então a atividade não mostra "para o time Time".
2. Dado uma entrada de atividade de ontem, quando o card abre, então ela mostra "ontem" e a hora, com a data completa ao passar o mouse.
3. Dado um time com outro nome, quando um card é criado para ele, então a atividade mostra o nome do time.
