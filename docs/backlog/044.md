# 044 · Estado do git no card do kanban

## Objetivo

Mostra no próprio card o estado da entrega no git, para o kanban responder "o que anda" sem abrir cada card.

## Comportamento

- O card com worktree mostra a branch, o tamanho do diff (linhas adicionadas e removidas) e o agente trabalhando nele, se houver.
- Com PR vinculado, o card mostra o estado do PR (aberto, mesclado, fechado) e do CI (rodando, passou, falhou).
- Clicar no estado do PR abre o PR; clicar no diff abre a tela de diff do card.
- Os dados são atualizados quando o worktree muda e quando a vigilância do PR consulta o estado.

## Estados e transições

Não modelado no diagrama.

## Critérios de aceite

1. Dado um card com worktree e alterações, quando o kanban é exibido, então o card mostra a branch e o número de linhas adicionadas e removidas.
2. Dado um card com PR e CI falhando, quando o kanban é exibido, então o card mostra o estado "CI falhou".
3. Dado um card sem worktree, quando o kanban é exibido, então nenhum dado de git aparece.
