# 053 · Limpar avisos de código morto do build

## Objetivo

Remove os avisos de código não usado do `cargo check`, para que um aviso novo não se esconda entre os antigos.

## Comportamento

- `cargo check --bins` termina sem avisos.
- Código realmente sem uso é removido; o que é usado só em teste fica marcado como tal.

## Estados e transições

Não se aplica.

## Critérios de aceite

1. Dado o repositório, quando roda `cargo check --bins` em `desktop/src-tauri`, então não aparece nenhum aviso.
2. Dado a remoção, quando roda `cargo test`, então todos os testes passam.
